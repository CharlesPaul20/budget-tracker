# SpendWise Dashboard Shell

## Project Description

SpendWise is a personal finance dashboard designed to help users view their budget, spending, savings, and expenses in one place.

This Week 4 project focuses on creating a dashboard layout using **CSS Grid and Flexbox**.

## Features

The dashboard contains:

* SpendWise sidebar navigation
* Personal Finance section
* Dashboard header
* User profile section
* Monthly spending summary
* Total Budget
* Total Spent
* Remaining Balance
* Monthly category breakdown
* Food category
* Transport category
* Rent category
* Entertainment category
* Savings category
* Utilities category
* Responsive layout for smaller screens

## Technologies Used

* HTML5
* CSS3
* CSS Grid
* CSS Flexbox

## Project Structure

### index.html

Contains the structure and content of the SpendWise dashboard.

### style.css

Contains the styling and layout of the dashboard. CSS Grid and Flexbox are used to organize the page.

### README.md

Contains information about the project, features, technologies, and project structure.

## CSS Grid

CSS Grid was used to create:

* The main dashboard layout
* The spending summary cards
* The monthly category layout

## CSS Flexbox

Flexbox was used to create:

* The sidebar navigation
* Header alignment
* User profile layout
* Category and content alignment

## Responsive Design

Media queries were added to make the dashboard adjust to smaller screen sizes such as tablets and mobile devices.

## How to Run

1. Open the project folder.
2. Open `index.html` in a web browser.
3. The SpendWise dashboard will be displayed.
