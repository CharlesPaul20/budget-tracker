# SpendWise - JavaScript Foundation

## Project Description

SpendWise is a simple budgeting application designed to help users understand and manage their spending.

For Week 5, the project has been enhanced with JavaScript so that users can enter their budget and expenses. The application then calculates and displays their remaining balance.

## JavaScript Concepts Implemented

The following JavaScript concepts were implemented:

- Variables
- Data types
- User input
- Type conversion
- Arithmetic calculations
- Functions
- Conditional statements
- DOM manipulation
- Event listeners
- Console output
