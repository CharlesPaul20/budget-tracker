# Personal Budget & Expense Tracker

## Week 3 – Visual Identity

This project is a Personal Budget & Expense Tracker built using HTML and CSS.

### Week 3 Improvements

- Added a consistent color palette.
- Added Google Fonts for headings and body text.
- Styled the expense table with borders, spacing, and alternating rows.
- Styled the expense form and button.
- Added rounded corners to cards, inputs, buttons, and sections.
- Applied padding, margins, and borders using the CSS box model.
- Added visual cards for the page header, expense form, and expense table.
