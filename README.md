# Personal Budget & Expense Tracker

## Project Description

This project is a Personal Budget & Expense Tracker built using HTML and CSS.

The project allows users to view a simple expense form and a table containing sample expenses.

## What I Built

### 1. HTML Structure
I created the main page structure using HTML.

### 2. Add Expense Form
The form contains:
- Expense Name
- Amount
- Category
- Add Expense button

The category uses a dropdown with:
- Food
- Transport
- Rent
- Entertainment
- Other

### 3. Expense Table
The table contains:
- Name
- Amount
- Category
- Date

It also includes five sample expense records.

### 4. Multimedia
I added:
- A budget tracker logo
- A YouTube video

### 5. Interactive Elements
I added a collapsible "How to use this tracker" section using `<details>` and `<summary>`.

### 6. CSS Styling
I used CSS to style the page, table, form, button, and other elements.

I also used advanced CSS selectors including:
- Descendant selectors
- Direct child selectors
- `:nth-child(even)`
- `:not()`
- `:focus`
- `:hover`

## Technologies Used

- HTML
- CSS

- `index.html` - Contains the structure and content of the website.
